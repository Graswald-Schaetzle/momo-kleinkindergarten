# Hund-Video (Startseite)

Freigestellte Version des Original-Videos `Hund_Hintergrund_F2EDE1_Flach.mov`
(flacher Hintergrund `#F2EDE1`), erzeugt ohne Lovable via ffmpeg Chroma-Key
(`colorkey=0xF3EDE1:0.045:0.0`):

- `momo-hund-alpha.webm` – VP9 mit echtem Alpha-Kanal (Chrome/Firefox/Android).
- `momo-hund-mustard.mp4` – H.264, Hund direkt auf den Senfton der Startseite
  (`#C8912F`) gerechnet, als Fallback für Safari/iOS (kein zuverlässiger
  Alpha-Video-Support dort).
- `momo-hund-poster.jpg` – Standbild aus der MP4-Version fürs `poster`-Attribut.
